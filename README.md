# PodnarHomePage

> A minimal personal homepage and link directory for all my web projects.

---

## Overview

PodnarHomePage is a simple, clean landing page that acts as a central hub linking to all of my other websites and projects. Built with plain HTML, CSS, and JavaScript — no frameworks, no dependencies.

---

## Tech Stack

| Tool | Purpose |
|------|---------|
| **HTML5** | Page structure |
| **CSS3** | Styling with CSS custom properties |
| **JavaScript** | Dark mode toggle |

---

## Features

- **Project card grid** — Responsive auto-fit grid linking to each project
- **Dark mode toggle** — Switches between light and dark themes via CSS variables
- Smooth hover animations on cards
